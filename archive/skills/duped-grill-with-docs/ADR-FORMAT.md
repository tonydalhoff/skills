# ADR Format

Store ADRs under `docs/adr/` with the next numeric prefix and a short kebab-case name.

```md
# <Decision title>

## Status

Accepted

## Context

<Why this decision is needed.>

## Decision

<What was chosen and why.>

## Considered options

- <Alternative and why it was rejected.>

## Consequences

- <Important downstream effect.>
```

Omit sections that add no value; a short ADR is preferable to ceremonial filler.
